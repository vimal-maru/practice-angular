1. Unit Testing with Jasmine & Karma

Unit testing focuses on testing individual units of code such as functions, components, or services in isolation.

Jasmine is a behavior-driven testing framework, while Karma is a test runner that executes tests in real browsers.

Key benefits:
  • Early detection of bugs
  • Improved code reliability
  • Confidence during refactoring

2. Component Testing

Component testing ensures that Angular components render correctly and behave as expected under different conditions.

It validates template rendering, input bindings, output events, and user interactions.

  • Testing component logic
  • Verifying DOM rendering
  • Simulating user interactions

3. Service Testing & HTTP Mocking

Service testing validates business logic and data operations implemented inside Angular services.

HTTP mocking allows simulating backend responses without making real network calls.

Common scenarios:
  • Mocking API responses
  • Testing error handling
  • Validating request payloads

4. E2E Testing Basics

End-to-end (E2E) testing verifies the entire application flow from the user's perspective.

It ensures that all integrated components work together correctly in a real-world scenario.

  • Testing complete user journeys
  • Validating navigation and routing
  • Ensuring critical workflows function correctly

5. Test Coverage & Best Practices

Test coverage measures how much of your codebase is exercised by automated tests.

High-quality tests focus on meaningful scenarios rather than achieving coverage numbers alone.

Best practices:
  • Test critical business logic first
  • Avoid brittle or overly complex tests
  • Keep tests fast and deterministic

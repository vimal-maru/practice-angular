1. CRUD with JSON Server

JSON Server is a lightweight tool used to create a fake REST API for development and testing purposes.

It allows developers to perform full CRUD operations without setting up a real backend.

Supported operations:
  • Create (POST)
  • Read (GET)
  • Update (PUT / PATCH)
  • Delete (DELETE)

2. API Call Integration

Angular integrates with backend systems using the HttpClient service to send and receive data over HTTP.

API integration is essential for building data-driven applications such as dashboards, admin panels, and user management systems.

  • RESTful API communication
  • Observable-based response handling
  • Error and loading state management

3. Resource API (resource & rxResource)

The Resource API provides a modern and declarative way to fetch and manage remote data using Angular Signals.

It simplifies API interaction by handling loading, error, and caching behavior automatically.

Key advantages:
  • Signal-based data fetching
  • Automatic state management
  • Reduced RxJS boilerplate

4. Session Storage

Session storage allows storing data temporarily in the browser for the duration of a page session.

Data is cleared automatically when the browser tab is closed.

  • User session data
  • Temporary UI state
  • Short-lived tokens

5. Local Storage

Local storage enables persistent storage of key-value data in the browser even after the page is refreshed or closed.

It is commonly used for saving user preferences and cached data.

Typical use cases:
  • Theme preferences
  • User settings
  • Offline caching

6. Cookies

Cookies are small pieces of data stored in the browser and automatically sent with HTTP requests.

They are often used for authentication, tracking, and session management.

  • Authentication tokens
  • Session identifiers
  • User preferences

7. Functional Guards & Resolvers

Functional guards and resolvers provide a more concise and readable way to protect routes and preload data.

They reduce boilerplate compared to class-based implementations.

Benefits:
  • Simpler syntax
  • Improved maintainability
  • Better alignment with functional patterns

8. Deferred Loading (@defer)

Deferred loading allows components or templates to be loaded only when they are needed.

This improves performance by reducing initial rendering cost and speeding up page load times.

Common scenarios:
  • Below-the-fold content
  • Heavy components
  • Conditional feature loading

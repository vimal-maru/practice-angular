1. Router Configuration

Angular routing enables navigation between different views or pages within a single-page application without reloading the browser.

Routes are defined by mapping URL paths to components using the Angular Router.

Core routing concepts:
  • Routes array
  • RouterModule configuration
  • router-outlet placeholder

2. Route Parameters & Query Params

Route parameters allow passing dynamic values through the URL path, while query parameters are used for optional or filter-based data.

  • Route params are part of the URL path
  • Query params follow the ? symbol
  • Both support reactive access and updates

These parameters are commonly used for detail pages, filtering, and pagination.

3. Lazy Loading Modules

Lazy loading improves application performance by loading feature modules only when they are needed.

This reduces the initial bundle size and speeds up application startup.

Advantages of lazy loading:
  • Faster initial load
  • Optimized bundle size
  • Better scalability

4. Route Guards & Resolvers

Route guards control access to routes based on conditions such as authentication or authorization.

Resolvers fetch required data before a route is activated, ensuring the component loads with complete data.

Common use cases:
  • Authentication checks
  • Role-based access control
  • Preloading route data

5. Nested Routing

Nested routing allows routes to be defined within other routes, enabling complex layouts with multiple router outlets.

This approach is commonly used in dashboards and admin panels.

  • Parent-child route relationships
  • Multiple router outlets
  • Shared layout components

6. Dynamic Routing & 404 Page

Dynamic routing enables handling of unknown or variable routes using wildcard paths.

A dedicated 404 (Page Not Found) component improves user experience by guiding users when an invalid URL is accessed.

Best practices:
  • Always define a wildcard route
  • Show user-friendly error messages
  • Provide navigation back to valid pages

7. Programmatic Navigation

Programmatic navigation allows route changes using code instead of template links.

It is commonly used after form submissions, login actions, or conditional navigation flows.

  • Navigate based on application logic
  • Pass route parameters dynamically
  • Control navigation behavior precisely

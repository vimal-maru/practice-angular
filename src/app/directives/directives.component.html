1. Directives Overview

Directives are special instructions in Angular that allow you to manipulate the DOM, change element appearance, or control rendering logic.

They extend HTML by adding custom behavior to elements.

Angular provides three types of directives:
  • Structural Directives
  • Attribute Directives
  • Custom Directives

2. Built-in Directives (ngIf, ngFor, ngSwitch)

Built-in structural directives control how elements are added or removed from the DOM.

  • *ngIf – Conditionally render elements
  • *ngFor – Render lists dynamically
  • *ngSwitch – Display content based on conditions
1. *ngIf & else directive example:

2024 is Leap Year

2025 is not Leap Year
2. *ngFor directive example:
  • {{user.userId}} - {{user.userName}} - {{user.userEmail}}
3. *ngSwitch directive example:

It's Monday

It's Tuesday

It's Wednesday

It's Thursday

It's Friday

It's Saturday

It's Sunday

It's Holiday

3. Attribute Directives (ngClass & ngStyle)

Attribute directives change the appearance or behavior of an element without changing the DOM structure.

  • ngClass – Apply CSS classes dynamically
  • ngStyle – Apply inline styles dynamically

4. Structural Directives

Structural directives modify the layout by adding or removing elements from the DOM.

Key characteristics:
  • Prefixed with *
  • Operate on templates
  • Modify DOM structure

5. Structural Directives vs New Control Flow

Modern Angular introduces a new template control flow syntax using: @if, @for, @switch, @empty.

This syntax improves readability, reduces boilerplate, and offers better performance compared to traditional structural directives.

Advantages of new control flow:
  • Cleaner syntax
  • Improved performance
  • Better type safety

6. Custom Directives

Custom directives allow you to create reusable behaviors that can be applied across multiple components.

  • Auto-focus inputs
  • Role-based UI rendering
  • Custom hover or highlight effects

7. Styling in Angular

Angular supports multiple styling approaches to keep applications modular and maintainable.

  • Component-level styles
  • Global styles
  • Dynamic styling using directives

Angular style encapsulation prevents CSS conflicts between components.

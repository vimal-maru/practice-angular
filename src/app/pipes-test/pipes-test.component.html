1. Built-in & Custom Pipes

Pipes are used to transform data directly in templates without modifying the original value.

  • Date
  • Uppercase / Lowercase
  • Currency
  • Async

Custom pipes help encapsulate reusable formatting logic.

2. Pure vs Impure Pipes

Pipes are categorized based on how often Angular executes them.

  • Pure Pipes – Execute only when input data changes
  • Impure Pipes – Execute on every change detection cycle
Best practice:
  • Prefer pure pipes for performance
  • Avoid impure pipes unless absolutely necessary
